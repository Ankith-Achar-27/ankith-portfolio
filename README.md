# Ankith H S — Portfolio

A responsive personal portfolio built with React, Vite, JavaScript, and plain CSS.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Personalize before publishing

- Add your own photo as `public/profile.jpg` (or update the image path in `src/App.jsx`).
- Add your resume as `public/resume.pdf`.
- Replace the placeholder LinkedIn URL and email address in `src/App.jsx`.
- Verify all project repository and live-demo links.
- Add real project screenshots under `public/` and update `src/data.js`.
- Do not publish the placeholder contact email or a resume link until you replace them.
